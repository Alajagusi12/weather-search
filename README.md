# 🌦️ Weather Search App

A simple, clean, and responsive weather search application that helps users check the weather in different locations.

🔗 Live Demo: https://alajagusi12.github.io/weather-search/

## 📌 About the Project

Weather Search is a web application I built to make checking the weather simple and convenient.

Users can search for a city to check its weather or use their current location to get location-based weather information.

The project focuses on simplicity, usability, and creating a clean experience that works across different screen sizes.

## ✨ Features

- 🌍 City Search: Search for weather information by entering a city name.
- 📍 Current Location: Use your device's location to check local weather.
- 📱 Responsive Design: Designed to provide a usable experience across different screen sizes.
- 🎯 Simple Interface: Clean and straightforward navigation.
- ⚡ Easy to Use: Find weather information with just a few clicks.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages for deployment
